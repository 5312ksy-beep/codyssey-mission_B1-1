01 — About

About Me

데이터를 다루는 태도에 대해

저는 복잡한 데이터를 검증하고, 실제 문제를 해결하는 답으로 바꾸는 데이터 분석가입니다.

수학과 빅데이터사이언스를 공부하며 공공데이터, 매출·소비 데이터 등 다양한 실제 데이터를 분석해 왔습니다. 정제된 예제 데이터가 아니라 결측과 이상치가 뒤섞인 현실의 데이터를 다루면서, 분석은 결국 데이터를 믿을 수 있게 만드는 일에서 시작한다는 것을 배웠습니다.

그래서 분석에 들어가기 전에 데이터의 구조와 품질을 꼼꼼히 확인합니다. 그리고 분석이 끝나면 그 결과를 표와 수치로 남겨두지 않고, 누구나 이해할 수 있는 인사이트와 서비스로 구현하는 것까지를 제 역할이라고 생각합니다.

  • 검증부터 시작합니다

    분석 전에 결측치·이상치·중복을 먼저 점검합니다. 잘못된 데이터 위에 쌓은 결론은 의미가 없기 때문입니다.

  • 실제 데이터를 다룹니다

    공공데이터, 매출·소비 데이터 등 현실의 지저분한 데이터를 정제하고 분석한 경험이 있습니다.

  • 전달까지 책임집니다

    분석 결과를 이해하기 쉬운 시각화와 서비스로 구현해, 실제 의사결정에 쓰이도록 만듭니다.
